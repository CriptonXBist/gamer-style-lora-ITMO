## 1. Кратко (TL;DR)

- Дообучил Qwen2.5-1.5B-Instruct методом LoRA на собственном датасете

## 2. Гипотеза и дизайн эксперимента

**Что меняем:** стиль ответов — геймерский сленг (Dota 2, CS2).
**Где проверяем перенос:**
1. строгий формат и арифметика (D01) — не деградировал ли базовый навык;
2. фактология на новой теме (D02) — не ломает ли стиль смысл;
3. игра вне выборки (D03, Deadlock) — перенос стиля или заучивание.

**Критерии успеха (4 свойства):** содержание, инструкция, язык,
стиль — оцениваются раздельно, шкала 0/1/2.

**Контрольные вопросы (dev-выборка):**

| ID | Вопрос | Что проверяет | Эталон |
|----|--------|---------------|--------|
| D01 | «Сколько будет 18 + 24? Верни только число.» | инструкция (формат) + содержание | ровно `42` |
| D02 | «Объясни в двух предложениях, почему небо голубое.» | содержание + стиль на новой теме | факт + лёгкий сленг |
| D03 | «Дай один короткий совет, как поднять ранг в Deadlock.» | перенос стиля на игру вне выборки | сленговый совет не из датасета |

**Принцип одного изменения:** между сравнениями меняется ровно один фактор
(адаптер вкл/выкл либо инструкция вкл/выкл); вопросы, шаблон диалога и
параметры генерации зафиксированы (`do_sample=False`, `max_new_tokens=100`).

## 4. Модель и окружение

- База: [Qwen/Qwen2.5-1.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct)
  (~1.5B параметров, ~3 ГБ весов в 16-битном формате).
- Метод: LoRA (PEFT), r=16, alpha=32, dropout=0.05,
  target_modules = [q/k/v/o_proj, gate/up/down_proj]; базовые веса заморожены
  (обучается <1% параметров).
- Окружение: Google Colab, GPU Tesla T4; обучение в **fp16**, т.к. T4
  (Turing) аппаратно не поддерживает bf16 (нужен Ampere+).
- Библиотеки: transformers, peft, trl, datasets, accelerate.

| Параметр SFTConfig | Значение | Комментарий |
|--------------------|----------|-------------|
| max_steps | 200 | |
| per_device_train_batch_size | 2 | |
| gradient_accumulation_steps | 4 | эффективный батч = 8 |
| learning_rate | 3e-4 | |
| max_length | 512 | |
| fp16 | True | ограничение T4 |

**Динамика loss:** старт ~2.5 → финиш 0.028.

**Интерпретация:** loss = −ln(p). Старт ~2.5 означает, что модель
угадывала следующий токен с вероятностью ~8%; финиш 0.028 — с вероятностью
~97%. Столь низкий финальный loss на 25 примерах — красный флаг
переобучения, а не показатель успеха: модель почти идеально воспроизводит
учебные токены.

## 6. Оценка: до / после / после + инструкция

Три режима на одинаковых вопросах:
- `ask_before` — базовая Qwen (LoRA отключён через `disable_adapter()`);
- `ask_after` — Qwen + LoRA;
- `ask_after` + системная инструкция — тот же адаптер, но с приоритетом
  формата и фактов над стилем.

### D01 — строгий формат и арифметика (1ая прогонка)
Вопрос: «Сколько будет 18 + 24? Верни только число.»

```
База:            42
+LoRA:           42
+LoRA+инструкция: 32   ← неверное число: деградация арифметики
```

### D02 — фактология на новой теме (1ая прогонка)
Вопрос: «Объясни в двух предложениях, почему небо голубое.»

```
База:    Небеса кажутся голубыми из-за отражения солнечного света...
         Солнце emits photons... видим зеленый или голубой цвет... 2. Г
+LoRA:   Небо — это тень от земли. Солнце фармит воздух, а земля его
         поглощает. Воздух под прямым углом к солнцу отражает цвет,
         и мы видим голубец. Это классика науки!
+LoRA+инструкция: Небо — это тень! Свет от земли разряжает твою пик,
         а затемнение создает палитру ясности. Это классика вардмафии —
         один хэдшот меняет облик саппорта на винрейтера...
```

### D03 — перенос стиля на игру вне выборки (1ая прогонка)
Вопрос: «Дай один короткий совет, как поднять ранг в Deadlock.»

```
База:    В Deadlock, чтобы подняться на более высокий уровень, важно
         следовать нескольким рекомендациям: 1. Улучшить знания и навыки...
+LoRA:   Бро, главное — это ластхит и денай. Не давай крипов вражескому
         саппорту, контролируй руну на 2 минуте...   ← дословный пример
         обучающего датасета про Доту
+LoRA+инструкция: Бро, главное — это ластхит и денай. Не давай крипов
         вражескому керри...   ← то же заучивание, инструкция не помогла
```

## 7. Разбор ошибок

1. **Переобучение.** loss 0.028 + дословное повторение на D03: на вопрос
   про Deadlock модель выдаёт учебный диалог про Доту. Переноса стиля нет —
   есть заучивание.
2. **Деградация базовых навыков.** D01: под системной инструкцией модель
   ответила 32 вместо 42 — ошибка арифметики появилась только после
   дообучения (catastrophic forgetting, лекция 2).
3. **Галлюцинации в фактах.** D02: «Солнце фармит воздух» — стиль подавил
   содержание; добавление инструкции сделало текст ещё менее связным.
4. **Инструкция не помогла.** В лекции системная инструкция подняла счёт
   строгих форматов с 0/2 до 1/2; у нас эффект нулевой/отрицательный:
   переобучение слишком глубокое, чтобы чиниться промптом.

**Защищаемый вывод:** на трёх dev-вопросах дообучение изменило стиль ответов,
но ухудшило содержание и следование инструкции; добавление системной
инструкции результат не улучшило. Утверждение «модель стала лучше»
не поддерживается данными; утверждение «модель переняла манеру, но
частично потеряла базовые навыки и зазубрила примеры» — поддерживается
приведёнными сравнениями.

---

## 8. Выводы и следующие шаги

1. Повторить обучение с `max_steps=60–80` (единственное изменение — число
   шагов) и сравнить на той же dev-выборке.
2. Расширить датасет до 100+ примеров, добавить другие игры и «негеймерские»
   темы, чтобы заучивание стало невозможным.
3. Добавить в обучающую выборку примеры арифметики/строгого формата —
   приём из лекции 2 против деградации навыков.
4. Выделить holdout-вопросы, которые не используются при подборе настроек.
